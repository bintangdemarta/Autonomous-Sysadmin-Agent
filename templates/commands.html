Configuration Format

The configuration is in JSON format with the following structure:

{
  "monitoring": [
    {
      "name": "Check RAM",
      "command": "free -h",
      "keywords": ["cek ram", "ram", "memory"],
      "description": "Displays system memory usage"
    },
    {
      "name": "Check Disk",
      "command": "df -h",
      "keywords": ["cek disk", "disk", "storage"],
      "description": "Displays disk space usage"
    }
  ]
}

Each command object can have the following properties:

  • name: Human-readable name for the command
  • command: The actual command to execute
  • keywords: Array of keywords that trigger this command
  • description: Description of what the command does
  • pattern: (Optional) Regex pattern to match more complex commands
