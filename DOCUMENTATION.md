# Autonomous Sysadmin Agent (Nexus-CLI)  
  
## Overview  
The Autonomous Sysadmin Agent (also known as Nexus-CLI) is a deterministic SSH automation tool that uses rule-based logic instead of AI/LLM to translate natural language commands into server commands.  
  
## Features  
- Natural language processing using rule-based mapping  
- Secure SSH connections to remote servers  
- Configurable command mappings via JSON  
- Safety mechanisms for dangerous commands  
- Support for dynamic arguments using regex patterns  
- Web interface for easier management  
  
## Installation  
1. Clone the repository  
2. Install dependencies with pip install -r requirements.txt  
3. Configure your server credentials in .env  
4. Run either the CLI or web interface  
  
## Usage  
- CLI: python main_app.py  
- Web: python web/app.py
